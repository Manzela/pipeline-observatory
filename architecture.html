Self-Improving Data Loop

3-Tier Dataset Flywheel

Intelligence is recursive. Every pipeline execution — success or failure — feeds a closed-loop data flywheel that continuously improves model quality through RLAIF-grade preference optimization.
T1
production-baseline
All production runs ingested. Raw I/O pairs across 17 prompt-specific partitions.
↓ O-R-A-V ≥ 0.7 && DEMAS PASS
T2
quality-approved
High-quality outputs curated as chosen examples for DPO training pairs.
↓ O-R-A-V < 0.5 || DEMAS FAIL
T3
failure-cases
Rejected outputs curated as rejected examples. Includes DEMAS failures + node errors.
DPO PREFERENCE PAIRS → LoRA FINE-TUNING → MODEL UPDATE

Margin-maximized (chosen, rejected) pairs with score gap ≥ 0.15 feed curriculum-based LoRA training
