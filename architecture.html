Infrastructure

Auto-Scaling Worker Pool

Modal workers scale from 0 to 1,000 concurrent instances based on queue depth and GPU utilization. LoRA adapters are LRU-cached in VRAM across the fleet.

Scaling Policy

↑ Scale up — queue depth > 50 requests
↓ Scale down — GPU < 20% for 5 min
◆ LoRA swap — <50ms adapter switch
◆ LRU eviction — coldest adapter freed
■ Fail-closed — instance fail → Firestore + halt
■ Cost guard — $50/mo cap auto-throttle
